# مراحل — الواجهة الأمامية (Frontend)

تطبيق Next.js (App Router + TypeScript + Tailwind CSS) يمثل واجهة منصة "مراحل". لتشغيله محليًا:

```bash
npm install
npm run dev
```

يفتح على [http://localhost:3000](http://localhost:3000). تحتاج ملف `.env.local` ببيانات مشروع Firebase — انظر `.env.example`.

للتفاصيل الكاملة عن بنية المشروع (الواجهة + الخلفية)، وخطوات النشر على Vercel وFirebase، راجع [README الرئيسي](../README.md).
